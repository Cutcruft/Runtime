# Документация

Карта документации проекта **CutCruft Runtime**.

| Документ | О чём |
|---|---|
| [Устройство Runtime.md](Устройство%20Runtime.md) | Внутреннее устройство ядра: домены, реестры, команды, сессии, WS-протокол, загрузка плагинов, жизненный цикл |
| [Устройство Плагинов.md](Устройство%20Плагинов.md) | Plugin API (SDK), манифест `config.yaml`, команды, сущности, зависимости, classloader-изоляция, сборка плагинов |
| [Архитектура Runtime.md](Архитектура%20Runtime.md) | Общая архитектура: слои, поток команды, файловая структура, формат хранения проекта |
| [Демо плагин.md](Демо%20плагин.md) | Эталонный разбор демо-плагинов (`demo` и `demo-storage`): модели, команды, связи, WS-сессия |

## Порядок чтения

1. **README** (корень репозитория) — что это и как запустить.
2. **Архитектура Runtime.md** — общая картина и термины.
3. **Устройство Плагинов.md** — если вы пишете плагин.
4. **Устройство Runtime.md** — если вы развиваете само ядро.
5. **Демо плагин.md** — рабочие примеры `demo`/`demo-storage`.

## Статус и соответствие коду

Документация поддерживается в актуальном состоянии вместе с рефакторингом ядра. При изменении публичных контрактов SDK или WS-протокола обновляйте соответствующие документы и примеры в этой папке.
