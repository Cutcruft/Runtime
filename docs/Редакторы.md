# Редакторы: конфиг → API движка и escape-hatch

Документ описывает четыре встроенных редактора (`RichText`, `Diagram`, `Scene3D`, `Canvas2D`), как их декларативный конфиг маппится на API движков (TipTap / X6 / three.js / нативный Canvas 2D), и как выйти за пределы конфига через `registerComponent`.

Редакторы доставляются **ленивыми чанками** ядра (`editorRegistry.ts`): тяжёлые библиотеки (TipTap, X6, three.js) грузятся только когда тип редактора появляется в конфиге страницы. Начальный бандл остаётся лёгким (~137 КБ).

## Общий конфиг редакторов (`EditorBaseConfig`)

Каждый редактор принимает `config` компонента типа `editor` на странице:

```kotlin
UiComponent("Editor", mapOf(
    "type" to "richtext",          // richtext | diagram | scene3d | canvas2d
    "config" to mapOf(
        "content" to mapOf("command" to "demo.loaddocument", "params" to mapOf("id" to DOC)),
        "save" to mapOf("command" to "demo.savedocument", "params" to mapOf("id" to DOC, "title" to "Doc")),
        "readonly" to false,
        "height" to "70vh",
        "placeholder" to "..."
    )
))
```

| Ключ | Тип | Назначение |
|---|---|---|
| `content` | `{command, params}` | Загрузка контента — команда возвращает сущность с JSON-полем `content` |
| `save` | `{command, params}` | Сохранение по дебаунсу 600 мс после изменения; `content` добавляется в params автоматически |
| `readonly` | `bool` | Запрет редактирования (тулбар/взаимодействия отключаются) |
| `disabled` | `bool` | Полностью неактивный |
| `height` | `string` | Высота редактора (CSS) |
| `placeholder` | `string` | Подсказка в пустом контенте (RichText) |

`content` — `DataBinding`, поддерживает `{...}` подстановку параметров из `context` (например `$row.id`).

## RichText — TipTap (`type: "richtext"`)

Реализация: `frontend/src/editor/UiRichText.vue`.

```kotlin
"config" to mapOf(
    "content" to mapOf("command" to "demo.loaddocument", "params" to mapOf("id" to DOC)),
    "save" to mapOf("command" to "demo.savedocument", "params" to mapOf("id" to DOC)),
    "contentFormat" to "json",        // json | html
    "placeholder" to "Start writing…",
    "extensions" to listOf(            // опции расширений
        mapOf("name" to "placeholder", "options" to mapOf("placeholder" to "…"))
    ),
    "toolbar" to listOf("bold", "italic", "underline", "strike", "code",
                        "heading1", "heading2", "heading3", "bulletList",
                        "orderedList", "taskList", "blockquote", "codeBlock",
                        "link", "image", "table", "undo", "redo"),
    "mentions" to mapOf("command" to "demo.mentions")  // @-mention, опции — команда плагина
)
```

Маппинг конфиг → TipTap API:

| Конфиг | API |
|---|---|
| `contentFormat` | сериализация: `editor.getJSON()` / `editor.getHTML()`, загрузка через `editor.commands.setContent` |
| `extensions[].name` | `StarterKit`, `Link`, `Underline`, `Table`, `TaskList`/`TaskItem`, `Placeholder`, `Image` |
| `toolbar` | порядок кнопок; отсутствие ключа — все, `toolbar: false` — скрыть |
| `save` | `@update` → debounce 600 мс → команда сохранения |
| `readonly` | `editor.setEditable(false)` |
| `mentions` | `@tiptap/extension-mention` + Suggestion: кандидаты грузятся командой плагина (`loadData`), массив `[{id,label}]` или `{items:[…]}`; вставка ноды `{type:'mention', attrs:{id,label}}`, рендер `@label`, round-trip в HTML |

## Diagram — AntV X6 (`type: "diagram"`)

Реализация: `frontend/src/editor/UiDiagram.vue`.

```kotlin
"config" to mapOf(
    "content" to mapOf("command" to "demo.loaddocument", "params" to mapOf("id" to DOC)),
    "save" to mapOf("command" to "demo.savedocument", "params" to mapOf("id" to DOC)),
    "grid" to true,          // сетка X6 {size:10, visible}
    "panning" to true,       // перетаскивание фона (leftMouseDown + mouseWheel)
    "mousewheel" to true,    // zoom колесом с ctrl/cmd, minScale 0.2, maxScale 3
    "layout" to mapOf("gapX" to 40, "gapY" to 40),  // шаг кнопки «Сетка»
    "toolbar" to listOf("addRect", "addEllipse", "addEdge", "layout", "fit", "delete")
)
```

Контент — JSON `{nodes, edges}`:

```json
{
  "nodes": [{ "id": "n1", "shape": "rect", "x": 40, "y": 40, "width": 140, "height": 48,
              "label": "Task", "fill": "#f6f8fb", "stroke": "#94a3b8" }],
  "edges": [{ "id": "e1", "source": "n1", "target": "n2", "label": "→",
              "line": "rounded", "color": "#64748b" }]
}
```

| Поле ноды | Аттрибуты X6 |
|---|---|
| `shape` | `rect` → shape `rect`; `ellipse` → `ellipse`; `image` → shape `image` с `imageUrl` |
| `label`, `fill`, `stroke`, `color` | `attrs.body.fill`, `attrs.body.stroke`, `attrs.label.text`, `attrs.label.fill` |

Маппинг конфиг → X6 API:

| Конфиг | API |
|---|---|
| `grid` | `new Graph({ grid: { size: 10, visible: true } })` |
| `panning` | `new Graph({ panning: { enabled, eventTypes: ['leftMouseDown','mouseWheel'] } })` |
| `mousewheel` | `new Graph({ mousewheel: { enabled, modifiers: ['ctrl','meta'] } })` |
| `snap` | плагин `Snapline` (snapping выпилен из ядра в X6 2.x) |
| `toolbar.addEdge` | режим «источник→цель»: `node:mousedown` → `cell:click` → `addEdge` |
| `toolbar.layout` | алгоритм грид-раскладки: сортировка по (y, x), `Math.ceil(sqrt(n))` колонок, `gapX/gapY` |
| `toolbar.fit` | `graph.zoomToFit({ padding: 24 })` |
| выделение | плагин `Selection` (`multiple`, `rubberband`) |
| `save` | события `cell:added/removed/change:*`/`edge:connected` → debounce → команда |

Рёбра строятся через `router`/`connector`: `manhattan|metro` → `connector: rounded`, `smooth|rounded` — напрямую; magnet на нодах включён.

Контекстное меню ноды: на `node:contextmenu` редактор сам открывает оверлей через `overlayService.onGesture({event: 'contextmenu', componentType: 'Diagram', objectType: 'diagram.node', componentId, row: {id, label}, x, y})`. Демо-триггер: `{event: contextmenu, objectType: 'diagram.node', overlay: 'diagram-node-menu'}`. Пункты меню — обычные клиентские экшены, в т.ч. новый `{action: 'editor', editor: 'diagram', command: 'duplicate'|'delete'|'front'|'back', params}`: команда уходит в событие `editor.command` на eventBus и исполняется редактором со скоупом по `componentId` (у страницы должен быть `id`, у экшена — `componentId` в параметрах оверлея).

## Scene3D — three.js (`type: "scene3d"`)

Реализация: `frontend/src/editor/UiScene3D.vue`.

```kotlin
"config" to mapOf(
    "content" to mapOf("command" to "demo.loaddocument", "params" to mapOf("id" to DOC)),
    "save" to mapOf("command" to "demo.savedocument", "params" to mapOf("id" to DOC)),
    "background" to "#eef2f7",
    "grid" to true,                       // GridHelper 10x10
    "autoRotate" to false,
    "camera" to mapOf(                    // начальная камера + «Reset camera»
        "fov" to 50,
        "position" to listOf(4, 3.5, 5),
        "target" to listOf(0, 0, 0)
    ),
    "lights" to mapOf(                    // сцена освещения
        "ambient" to mapOf("intensity" to 0.7),
        "directional" to mapOf("intensity" to 1.2, "position" to listOf(5, 8, 6))
    ),
    "toolbar" to listOf("addBox", "addSphere", "addCylinder", "delete", "resetCamera")
)
```

Контент — JSON `{objects, background, grid}`:

```json
{
  "objects": [
    { "id": "b1", "kind": "box", "position": [0, 0.5, 0], "color": "#6b8afd" },
    { "id": "m1", "kind": "model", "position": [2, 0, 0], "modelUrl": "/plugin-assets/demo/assets/scene.glb" }
  ]
}
```

Маппинг конфиг → three.js API:

| Конфиг | API |
|---|---|
| `camera.fov/position/target` | `PerspectiveCamera(fov, aspect)`, `camera.position.set(...)`, `controls.target.set(...)`; применяется при старте и в `resetCamera` |
| `lights.ambient.intensity` | `new THREE.AmbientLight(0xffffff, intensity)` |
| `lights.directional.intensity/position` | `new THREE.DirectionalLight(...)`, `dir.position.set(...)` |
| `background` | `renderer.setClearColor` |
| `grid` | `new THREE.GridHelper(10, 10, ...)` |
| `autoRotate` | `OrbitControls.autoRotate` |
| `content.objects[].kind` | `BoxGeometry`/`SphereGeometry`/`CylinderGeometry`; `model` → `GLTFLoader` + `URL` резолв |
| pick по клику | `Raycaster` + `intersectObjects`, поиск по `userData.kind` |

Контент из демо содержит `background`/`grid` — они же пишутся обратно при сохранении.

## Canvas2D — нативный Canvas 2D (`type: "canvas2d"`)

Реализация: `frontend/src/editor/UiCanvas.vue`.

```kotlin
"config" to mapOf(
    "content" to mapOf("command" to "demo.loaddocument", "params" to mapOf("id" to DOC)),
    "save" to mapOf("command" to "demo.savedocument", "params" to mapOf("id" to DOC)),
    "grid" to true,                  // пунктирная сетка 20px
    "tool" to "draw",                // инструмент по умолчанию
    "colors" to listOf("#111827", "#ef4444", "#3b82f6", "#10b981", "#f59e0b", "#8b5cf6"),
    "widths" to listOf(2, 4, 8),
    "toolbar" to listOf("select", "pan", "draw", "erase", "rect", "ellipse",
                        "line", "arrow", "front", "back", "clear")
)
```

Контент — JSON `{elements}`:

```json
{ "elements": [
  { "type": "rect", "points": [{ "x": 10, "y": 10 }, { "x": 80, "y": 50 }],
    "color": "#3b82f6", "width": 4 }
] }
```

`type` элемента: `path` (свободный штрих), `rect`, `ellipse`, `line`, `arrow`.

Инструменты и взаимодействия:

| Инструмент | Поведение |
|---|---|
| `select` | выделение кликом (topmost), **перемещение** перетаскиванием, **resize** за 8 ручек (Shift — сохранить пропорции), Delete/Backspace — удаление |
| `front` / `back` | z-order: на передний/задний план (или `⌘[` / `⌘]`) |
| `pan` | перетаскивание фона |
| `draw` | свободный штрих |
| `erase` | стирание по пересечению с точками |
| `rect`/`ellipse`/`line`/`arrow` | рисование примитива drag-ом |
| `clear` | очистить доску |

Zoom — колесом мыши (пивот под курсором); двойной клик — сброс вида. Всё рисуется нативным Canvas 2D API без внешних зависимостей (канвас ~9 КБ).

## Общая модель сохранения

Все редакторы:

1. **Загрузка** — `content` биндинг: команда возвращает сущность, `content` парсится как JSON структуры редактора.
2. **Редактирование** — события изменений (update/change/pointerup/cell:change) → debounce 600 мс.
3. **Сохранение** — команда `save.command` с `params + { content: JSON.stringify(...) }`.

Проверка / откат: если `content` невалиден, редактор остаётся пустым без падения страницы.

## Escape-hatch: `registerComponent`

Декларативный конфиг покрывает демо-скоуп. Для произвольной логики плагин может зарегистрировать **собственный Vue-компонент** по типу:

```ts
import { registerComponent } from '../renderer/componentRegistry'

registerComponent('my-editor', {
  props: ['config', 'context'],
  setup(props) {
    // props.config — Map<String, Any> из UIDefinition
    // props.context — BindingContext (параметры строки, роутинга и т.п.)
  },
  // template…
})
```

Тип компонента указывается в `UIDefinition.componentType`; `ComponentHost.vue` сначала пробует `editorRegistry` (ленивые редакторы), затем builtin-реестр, затем кастомные типы. `registerComponent` возвращает функцию отмены регистрации.

Для доставки JS-кода плагинов (бандл через `/plugin-assets/<pluginId>/<path>`) — это **будущий** механизм; сейчас кастомные компоненты добавляются в бандл ядра (`main.ts`), либо плагин может статически подключать их через загрузку скрипта из своего JAR.

## Строки редакторов и i18n

Все строки тулбаров берутся из `core.*` каталога (`editor.canvas.*`, `editor.diagram.*`, `editor.scene3d.*`, `editor.saved` и т.д.) через `t(key)`. Плагин переопределяет текст, указывая свой каталог `messages/<lang>.json` — ключи агрегируются и неймспейсятся как `<pluginId>.<key>`.

Ссылка на перевод в конфиге — интерполяция `{{<pluginId>.<key>}}` в любом строковом значении (включая частичную, внутри текста):

```kotlin
"title" to "{{demo.page.boards}}",              // целая строка
"title" to "{{demo.app.title}} · {{demo.app.edition}}", // частичная
"confirm" to "{{demo.tasks.complete.confirm}}"
```

Резолв происходит на клиенте при рендере конфига (`deepTranslate` в `useCfg`/`tr`): выбранная локаль → `defaultLocale` → сырой ключ. Ключи объявляются просто ключами в `messages/<lang>.json`, отдельной декларации не требуется. Для параметризованных строк в коде остаётся `t('core.table.rows', { count })` (плюрализация `_one`/`_many`).
